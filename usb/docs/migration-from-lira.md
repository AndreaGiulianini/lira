# Migration from Lira

The generator in `../lira/source` is reused. Lira's `circuit.py` is the single description of the
connectivity; everything else (PCB placement, routing, schematic, BOM, checks, plate, case) is derived
from it. So the migration is mostly: **fork the source tree, replace the MCU/power section, keep the
audio and the matrix, adapt placement and firmware.**

## Reuse unchanged

| Part of Lira | Why it carries over |
|---|---|
| USB-C receptacle + USBLC6 ESD + CC resistors | identical |
| CH334P hub + 12 MHz crystal | identical |
| CM108B codec + all its regulator/reference capacitors + 22 Ω USB resistors | identical |
| TPA6132A2 amplifier + charge-pump caps + gain jumper + output beads | identical |
| PJ-320D-4A headset jack | identical |
| Key matrix: 57 Kailh hot-swap sockets + 1N4148W diodes | identical |
| `layout.py` | identical (the key arrangement does not change) |
| Plate geometry (`mount.py`, `gen_plate.py`, `gen_plate_print.py`) | identical (the ears/tabs are independent of the MCU) |
| Case + fit check (`case/`) | the electronics strip changes; the rest is reused |
| Build tooling: `gen_pcb.py`, `route.py`, `repair.py`, `finish_pcb.py`, `verify_netlist.py`, `jlc_export.py`, `sanitize.py` | identical |
| `check_circuit.py` | reused, but the E73/charger/module checks must be replaced by RP2040/flash/crystal checks |

## Change

| Lira | Lira USB |
|---|---|
| E73 nRF52840 module (E73_PINS, E73_GPIO, pad map) | **RP2040** QFN-56 + W25Q128 flash + 12 MHz crystal |
| BLE antenna keep-out (26 × 4.65 mm, both layers) | **removed** — the strip can be full copper |
| Battery JST + MCP73831 charger + SI2301/B5819W power path + divider | **removed** — USB-only |
| 32.768 kHz crystal | **removed** |
| TPS22919 audio load switch + `AUD_EN` (P1.02) + `audio_gate.rs` | **removed** — audio always on with USB |
| AP2112K second rail (switched 3.3 V for externals) | never existed here |
| RMK (Rust) + Vial, `keyboard.toml` from `gen_firmware.py` | **QMK + Vial** (generated by hand or a new generator) |
| Battery ADC (P0.31 divider) | **removed** (or a VBUS presence divider if desired) |
| SWD bootloader-flash-once | **native UF2** via BOOTSEL; SWD pads kept only for recovery |

## Suggested fork

```
cp -R ../lira/source ./source          # then edit
```
1. Replace `pcb/circuit.py`'s module + power sections with `hardware/circuit.py` (this file's sibling).
2. Keep `circuit.audio()` and `circuit.matrix()` from Lira; delete the load-switch parts and `AUD_EN`.
3. Adapt `pcb/electronics.py` placement for the smaller MCU block (7 × 7 mm + flash + crystal) and the
   freed-up area where the antenna keep-out and the battery parts were.
4. Regenerate: `make pcb schematic verify check fab`, then the case.
5. Replace the firmware with a QMK + Vial keyboard for RP2040.

## Layout notes

- **No antenna keep-out.** The top and bottom copper can be continuous; the ground-plane stitching
  can stay coarse.
- **RP2040 decoupling is dense** (~20 × 100 nF): place one capacitor per supply pin, close, plus the
  1 µF on VREG_IN/VREG_OUT. This is the part of the layout that deserves hand work.
- **QSPI tracks** (RP2040 ↔ flash) are fast: keep them short and direct, as the HDG asks.
- **12 MHz crystal** close to XIN/XOUT, load caps to a solid ground, keep the tracks short.
- The RP2040 USB goes to hub **port 3** through the 27 Ω resistors; the CM108B stays on port 2.
